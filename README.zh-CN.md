# BetterTheEmby

[English](README.md) · **中文**

一个 Emby 服务器插件，让 Emby 4.9 自带的网页端换上现代化的外观，并补上它缺少的功能：
- Apple TV 式的首页和详情页
- Apple Music 式的专辑配色和歌词
- 流畅的动画
- 精简的媒体库标签
- 按标题和拼音搜索
- 手机布局
- 从网易云音乐和 Apple Music 补全艺人与专辑资料

全部功能都在一个插件 `BetterTheEmby.dll` 里。插件在服务器启动时把样式和脚本注入 Emby 自带的网页端，不需要手动改 Emby 的安装文件，也不需要另外部署前端。每一项功能都可以在插件设置页里关掉。

> 需要 **Emby Server 4.9.5.0**。插件依赖这个版本网页端的结构，建议把镜像固定在 `emby/embyserver:4.9.5.0`。

## 功能

### 外观与动画（Modern UI）

- **首页和媒体库**：
  - 顶部是全宽横幅，显示标题 Logo、评分、简介，以及播放、详情、收藏按钮。
  - 页面背景是横幅当前那张图的模糊版，横幅底部无缝融进去。
  - 鼠标停在卡片上时，背景换成那部作品。
- **详情页**：
  - 全宽背景大图带视差，标题换成 Logo，海报和各行文字依次浮现。
  - 剧集、季、单集共用一张背景图，切换时背景不动。
- **卡片**：悬停时抬起，并朝指针倾斜、带高光；点击后海报飞到详情页，返回时再飞回来。
- **界面外壳**：毛玻璃顶栏和菜单，标签栏用滑动的选中块，侧边栏只有一块会滑动的高光。
- **顶部分类**：内容按所选标签的左右方向滑入，系列和原声子分类首次进入时也有过渡；快速切换会取消前一次动画。
- **视频播放器**：更柔和的渐变、加粗的进度条、毛玻璃按钮；跳过片头按钮从下方滑入。
- 系统开启「减少动态效果」时，所有动画都会关闭。

### 音乐（Album Tint）

- 专辑页、全屏播放器和底部播放条随专辑封面取色。
- 手机与电脑使用同一张封面样本取色，专辑渐变背景不再混入继承的艺人图。
- Apple Music 式的封面和歌词：
  - 当前行发光，其余行按距离模糊，滚动平滑。
  - 双语 LRC 歌词按组显示。
  - 鼠标指到某一行会显示它的时间，点击即跳转。
- 在播放条或专辑页和播放器之间切换时，封面会飞过去。
- 开关歌词或播放队列时，电脑端封面、进度条和按钮随面板一起滑到新位置；手机端大封面会缩成标题旁的小封面（关闭时再放大回去）。

### 媒体库

| 媒体库 | 标签 |
|---|---|
| 电影 / 剧集 | 影片或节目 · 推荐 · 收藏 · **系列** |
| 音乐 | 专辑 · **艺人** |
| 在「按文件夹分类」里配置的音乐库 | 每个文件夹一个标签，可选一个「全部」 |

- **系列**：数据来自 Emby 的合集。把同一系列的剧集和剧场版放进一个合集，它们就按上映顺序出现在这里，附带封面、年份、类型和简介。点击系列封面或标题进入详情、返回列表时，封面沿用普通卡片的转场。
- **艺人**：每位艺人占一行：照片、名字、专辑数、风格、简介和专辑。
- **按文件夹分类**：
  - 适合按文件夹整理的音乐库，比如按版本、按地区分的游戏原声。
  - 每个标签显示一个文件夹里的专辑，按文件夹名排序（数字按大小，中文按拼音），用宽卡片展示，带前几首歌。
  - 配置的标题前缀也会在首页对应音乐库的专辑卡片中省略。
  - 配置格式见[技术文档](docs/TECHNICAL.md#folder-tabs)。
- **艺人页**：
  - 显示照片、模糊色调背景，以及一块完整简介「关于」。
  - 还没有简介的艺人，管理员打开页面时会自动去查一次。
- **字母索引**：媒体库右侧的索引栏显示拼音首字母 A–Z，而不是汉字，而且每个字母都在（Emby 原本最多只列 27 个字）。
- **简化版本名称**：详情页的「版本」下拉框只显示第一个「 - 」之后的内容，例如 `天气之子 - 4K BluRay-Remux … - Xcat` 显示为 `4K BluRay-Remux … - Xcat`（前面的片名页面标题里已经有了）。
- 视频详情的下拉框及电脑端选项菜单与封面使用相同圆角；选中项保持浅灰底和圆点，高亮铺满菜单，不留边缘空隙。

### 搜索

- 列出**节目、电影、专辑和专辑艺人**；专辑按标题或专辑艺人匹配，**单集和单曲只有自己的名字匹配时才出现**。搜剧名不会再把整部剧的每一集都列出来。
- **拼音**：支持全拼和首字母，`gdyg`、`guduyaogun` 都能搜到「孤独摇滚」，n 和 l 不分。
- **速度快**：标题和专辑艺人按媒体库缓存，在浏览器里匹配；缓存后一次搜索最多只发两个请求到服务器。
- 侧边栏搜索框的联想用同一套结果，按回车打开搜索页。

### 手机

- 单季节目打开时默认选中第一集。卡片宽度固定，点选后立即显示蓝框，后续集平滑滑到中央。
- 手机视频详情滚动时保留顶部的返回、搜索和更多。切换简介长短不同的集时，选集条保持原位，蓝框标记当前集。媒体库字母索引支持按住滑动，手机专辑四个操作按钮并排显示。
- 手机首页、媒体库、搜索及各类媒体详情共用右侧整页推入和返回转场。剧集详情上下滑时，剧照从顶部缩小并淡出，徽标和播放控件以原尺寸随内容滚动。
- 手机首页头图给徽标和标题预留同一块空间。滑动途中加载好的徽标会等画面停稳后再原位淡入。

- 季集页压紧首屏，长简介点开阅读，按返回键可关闭并留在原页。Safari 使用原生轨道选项框，其他浏览器使用桌面式弹出菜单。手机歌词全屏与播放控件之间平滑切换。

- 手机节目直接进入正片季的横向选集。点击季名即可在当前页面切换其他季和特别篇。选集时蓝框滑到新卡片。音乐队列同时显示随机和循环控件。

- 专辑页采用左侧大封面、右侧标题／艺人／专辑信息的横向排版，下方保留整行播放控件；长文字自然换行。
- 去掉底部标签栏，搜索放在右上角，专辑三列显示；悬浮顶栏按钮与标签使用更实的深色玻璃底，在封面上也容易看清；标签很多的媒体库可以左右滑动标签。
- 全屏播放器的歌词和翻译字号更小，给完整句子留出空间。
- 电脑端快速切换歌词和队列时，面板与播放控件从当前位置继续过渡。
- 动画更克制：每页只有一次短淡入。
- 页面像普通网站一样整页滚动：往下滑时 Safari 的工具栏自动收起，内容一直延伸到状态栏和工具栏下面，点一下状态栏回到顶部。回到某个页面或标签时，停在上次离开的位置。
- **iPhone 真正全屏**：在 Safari 里点「分享 → 添加到主屏幕」。从主屏幕打开时，Emby 不带 Safari 的地址栏和工具栏，页面一直延伸到状态栏下面。

### 元数据：网易云音乐与 Apple Music

为音乐库提供两个元数据提供者：

- **NetEase Music**：
  - 补全艺人的简介和照片，以及专辑的简介、发行日期、厂牌和封面。
  - 匹配很严格：只认完全一致的名字或网易云记录的别名。
  - 刷新时只补空着的字段。
- **Apple Music**（iTunes 公开搜索接口）：
  - 补网易云没有的专辑发行日期、类型、厂牌和 1200px 封面。
  - 允许繁简异体字匹配，但同时要求艺人一致、年份相近。

网易云会限制查询频率。插件默认每 1.5 秒查一次，被拒后暂停一段时间，剩下的等下次刷新再补。可选的登录 Cookie 和默认关闭的「轮换来源地址」见[技术文档](docs/TECHNICAL.md#netease-cloud-music-metadata-neteasecs)。

### 加载更快

Emby 网页端每次打开都要重新确认约 110 个文件。插件把 Emby 自带的空 `serviceworker.js` 换成一个缓存：
- 重复访问时，请求数降到 7–9 个。
- 在手机网络的延迟下，页面出现时间从约 1.8 秒降到约 0.4 秒。

这项只在 HTTPS 下生效。

## 安装

1. 从 [最新 Release](https://github.com/Plantforlife/BetterTheEmby/releases/latest) 下载 `BetterTheEmby.dll`，或者按下文自己编译。
2. 放进 Emby 的插件目录 `<emby-config>/plugins/`。
3. 重启 Emby，浏览器按 Ctrl+F5 刷新。

从旧版 *Album Tint & Modern UI*（`AlbumTint.dll`）升级，见[升级说明](docs/TECHNICAL.md#upgrading-from-albumtint)。

### 启用元数据提供者

1. 打开 **控制台 → 媒体库**，编辑音乐库：
   - 在「音乐艺术家」和「音乐专辑」的元数据下载器、图片下载器里勾选 **NetEase Music**，并拖到第一位。
   - 在「音乐专辑」里再勾选 **Apple Music**，放第二位。
2. 在媒体库上选择 **刷新元数据 → 搜索缺少的元数据**，保持「替换现有图片」不勾选，这样只补缺的。
3. 某位艺人匹配错了，就在该条目上用 **识别**，从 NetEase Music 的候选里选对的那个。

## 设置

**控制台 → 插件 → BetterTheEmby → 设置**，保存后网页端刷新一次即生效。

| 分组 | 设置项 |
|---|---|
| 外观 | 现代外观 · 专辑配色与歌词 · 手机布局 · 网页缓存 |
| 媒体库 | 精简标签 · 「系列」标签 · 「艺人」标签 · 按文件夹分类（JSON） · 简化版本名称 |
| 搜索 | 按标题搜索 · 拼音搜索 · 拼音字母索引 |
| 网易云 | 查询间隔 · 轮换来源地址（默认关闭）· Cookie（可选） |

全部设置项和默认值见[技术文档](docs/TECHNICAL.md#settings)。

### 按文件夹分类的示例

```json
[
  {
    "library": "Genshin OST",
    "allTab": "全部",
    "hide": "精选原声带",
    "stripPrefix": "原神 - ",
    "shelves": [
      { "folder": "场景OST", "tab": "地区OST" },
      { "folder": "版本OST", "tab": "流星的轨迹" },
      { "folder": "角色OST", "tab": "闪耀的群星" },
      { "folder": "主题OST", "tab": "珍珠之歌" },
      { "folder": "EP", "tab": "EP" }
    ]
  }
]
```

各字段的含义：
- `library`：媒体库名，也可以写成 `/正则/`。
- `shelves`：库根目录下的文件夹，以及显示它的标签名。
- `allTab`：可选，额外加一个「全部」标签。
- `hide`：可选，名字匹配这个正则的专辑不显示。
- `stripPrefix`：可选，所有专辑标题共有的前缀，在文件夹标签和首页对应音乐库的专辑卡片中省略，不改动专辑元数据。

## 编译

需要 .NET SDK（6.0 或更新）。

```bash
# 从 Emby 服务器（容器里的 /system 目录）复制
# MediaBrowser.Common.dll、MediaBrowser.Controller.dll、MediaBrowser.Model.dll 到 ./ref/
dotnet build -c Release
# 输出：bin/Release/netstandard2.0/BetterTheEmby.dll
```

`ref/` 里的 Emby 程序集属于 Emby，只用于编译，不包含在本仓库中。

## 关闭与卸载

- **对所有人关闭**：在设置页里关掉对应功能。
- **只在某个浏览器里关闭**：在开发者工具控制台运行 `ModernUI.disable()` / `ModernUI.enable()`、`AlbumTint.disable()` / `AlbumTint.enable()`。
- **卸载**：控制台 → 插件 → BetterTheEmby → 卸载。注入的内容立即移除，浏览器缓存也会清掉，刷新页面即可。手动删除 DLL 的做法见[技术文档](docs/TECHNICAL.md#turn-off--uninstall)。

## 已知限制

- 只针对 Emby 4.9.5.0 的网页端，其他版本的类名可能有变化。
- 只作用于 Emby 自带的网页端（浏览器，以及直接打开服务器网页的客户端），不影响 Emby 官方的原生 App。
- 歌词模糊和页面模糊背景会用到 GPU，很老的显卡上可能掉帧。
- 部分细节依赖较新的 CSS（`@starting-style`、`:has()`），旧浏览器上只是没有动画。
- 网易云和 Apple 的网页接口不是官方 API，以后可能会变。
